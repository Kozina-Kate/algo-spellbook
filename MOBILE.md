# Мобильная архитектура Algo Spellbook

Сейчас мобильная версия — адаптивная PWA. Она устанавливается из браузера,
работает в отдельном окне и кэширует курс для чтения без сети.

Capacitor уже подключён как мост к будущим нативным приложениям. В нативной
сборке Astro использует корневой `base`, а в обычной — `/algo-spellbook` для
GitHub Pages. Контент в обоих случаях берётся из `src/content/docs`.

## Первый запуск нативного проекта

Требования: Android Studio для Android, Xcode и macOS для iOS.

```bash
npm install
npm run mobile:add:android
npm run mobile:add:ios
npm run mobile:sync
```

Папки `android/` и `ios/` генерируются Capacitor только тогда, когда начинается
работа над соответствующей платформой. До этого в репозитории нет тяжёлых
платформенных проектов и устаревающих служебных файлов.

## Открыть проект в IDE

```bash
npm run mobile:open:android
npm run mobile:open:ios
```

Перед каждой нативной сборкой выполните `npm run mobile:sync`: команда собирает
Astro с правильным путём ресурсов и копирует `dist/` в обе платформы.

## Как развивать приложение

Следующий логичный слой — хранение прогресса локально через отдельный модуль с
интерфейсом репозитория. Веб-реализация может использовать IndexedDB, нативная —
плагин Capacitor Preferences или SQLite. Такой интерфейс не связывает контент
и UI с конкретным хранилищем и позволяет позже добавить аккаунт и синхронизацию.
