# Как писать уроки для Algo Spellbook

Этот шаблон сохраняет единый учебный ритм базового курса. Он рассчитан на
человека, который ещё не умеет программировать и может не знать значения
терминов, привычных разработчику.

## Принципы

1. Один урок вводит одну основную идею и опирается только на пройденные темы.
2. Новый термин объясняется до первого содержательного использования.
3. Пример сначала предлагается прочитать или проследить вручную, затем запустить.
4. Каждая использованная функция и операция объясняется рядом с кодом.
5. Формальные упражнения берутся из существующих публичных задач с прямой
   ссылкой на источник. Условие пересказывается, а не копируется дословно.
6. Решение скрывается в `<details>`, чтобы ученик сначала сделал попытку сам.
7. Урок заканчивается измеримым чеклистом навыков и ссылками назад/вперёд.

## Автоматическая проверка

Команда `npm run check:lessons` проверяет количество базовых уроков, frontmatter,
обязательные секции, блок ответа, чеклист, публичный источник и отсутствие
маркеров незавершённого текста. Она также запускается внутри `npm run check`.

Автоматическая проверка не оценивает педагогическое качество. Перед коммитом
нужно отдельно перечитать урок глазами новичка: каждое ли слово понятно,
можно ли выполнить упражнение по уже пройденному материалу и объяснена ли каждая
строка решения.

## Алгоритмические главы после базового курса

Алгоритмическая глава может сохранять подробный справочный материал, но её
первые абзацы должны дать новичку безопасный вход:

1. Сразу после ссылки на оглавление расположен `:::note[Перед началом]`.
2. В блоке перечислены конкретные базовые уроки JavaScript, необходимые для
   чтения кода. Нельзя ограничиваться формулировкой «нужно знать основы».
3. Там же дана короткая карта преобразования решения:
   `простое решение → узкое место → паттерн → улучшенный код → сложность`.
4. Карта ведёт на общую памятку
   [«Как работать с алгоритмической главой»](./src/content/docs/kak-rabotat-s-algoritmicheskoy-glavoy.md).
5. Новый синтаксис, которого не было в базовом курсе, объясняется локальной
   подсказкой перед первым использованием. Подсказка объясняет только нужную
   конструкцию и не превращается во второй учебник JavaScript.

Команда `npm run check:lessons` проверяет и девять базовых уроков, и наличие
переходных блоков во всех алгоритмических главах.
