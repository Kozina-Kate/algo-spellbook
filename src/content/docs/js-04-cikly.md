Цикл повторяет один блок кода. Без цикла пришлось бы писать одинаковые инструкции вручную для каждого элемента, а программа работала бы только с заранее известным количеством данных.

**Итерация** — один повтор тела цикла.

:::note[Перед началом]
**Урок 4 из 9 · 25–30 минут**

**Нужно знать:** `let`, сравнения и `if`. **После урока:** сможете повторить действие заданное число раз и пройти по всем элементам массива.
:::

## Цикл for по шагам

```js
for (let index = 0; index < 3; index += 1) {
  console.log(index);
}
```

В заголовке `for` три части:

1. `let index = 0` выполняется один раз перед стартом.
2. `index < 3` проверяется перед каждой итерацией.
3. `index += 1` выполняется после каждой итерации.

Вывод: `0`, затем `1`, затем `2`. При `index === 3` условие становится ложным, и цикл заканчивается.

Запись `index += 1` означает то же, что `index = index + 1`.

## Зачем начинать с нуля

Индексы массива в JavaScript начинаются с `0`.

```js
const colors = ["red", "green", "blue"];

console.log(colors[0]); // "red"
console.log(colors[1]); // "green"
console.log(colors[2]); // "blue"
```

Поэтому типовой обход массива выглядит так:

```js
for (let index = 0; index < colors.length; index += 1) {
  console.log(colors[index]);
}
```

`colors.length` — количество элементов. Последний допустимый индекс равен `length - 1`, поэтому используется строгое сравнение `<`, а не `<=`.

## for...of: когда нужен элемент, а не индекс

```js
const numbers = [4, 7, 2];

for (const number of numbers) {
  console.log(number);
}
```

На каждой итерации переменная `number` получает очередное значение массива. Этот вариант короче и удобнее, если позиция элемента не нужна.

:::note
`for...of` перебирает значения массива. `for...in` перебирает имена свойств и для обычного обхода массива в этом курсе не используется.
:::

## while: повторяем, пока условие истинно

```js
let value = 1;

while (value < 10) {
  value *= 2;
}

console.log(value); // 16
```

`while` удобен, когда заранее неизвестно количество повторов. Здесь число удваивается, пока остаётся меньше `10`.

Цикл обязан приближаться к завершению. Если `value` не менять, условие навсегда останется истинным и получится бесконечный цикл.

## Сквозная задача: суммируем положительные числа

Теперь можно почти полностью решить [Sum of positive](https://www.codewars.com/kata/5715eaedb436cf5606000381/javascript):

```js
const numbers = [1, -4, 7, 12];
let positiveSum = 0;

for (const number of numbers) {
  if (number > 0) {
    positiveSum += number;
  }
}

console.log(positiveSum); // 20
```

Пошагово:

1. `positiveSum` начинается с нуля.
2. `for...of` по очереди берёт `1`, `-4`, `7`, `12`.
3. `if` пропускает отрицательное число.
4. Положительные числа добавляются к накопленной сумме.
5. После цикла в `positiveSum` хранится окончательный ответ.

Переменная, в которой постепенно накапливается результат, называется **аккумулятором**.

## Таблица выполнения

| Итерация | `number` | `number > 0` | `positiveSum` после шага |
| --- | ---: | --- | ---: |
| начало | — | — | 0 |
| 1 | 1 | true | 1 |
| 2 | -4 | false | 1 |
| 3 | 7 | true | 8 |
| 4 | 12 | true | 20 |

Такая таблица называется **трассировкой**. Она помогает понять цикл и найти ошибку без догадок.

## Предскажите результат

```js
let total = 0;

for (let index = 1; index < 5; index += 1) {
  total += index;
}

console.log(total);
```

<details>
<summary>Ответ</summary>

Цикл использует значения `1`, `2`, `3`, `4`. Итог: `1 + 2 + 3 + 4 = 10`. Значение `5` не попадает в цикл из-за условия `index < 5`.

</details>

## Измените код

Измените цикл суммы так, чтобы он складывал только отрицательные числа. Затем сделайте второй вариант, который считает количество положительных чисел, а не их сумму. Перед запуском заполните трассировочную таблицу для двух первых итераций.

## Самостоятельная практика: Sum of positive

Решите ту же задачу [Sum of positive](https://www.codewars.com/kata/5715eaedb436cf5606000381/javascript) самостоятельно для массива `[-2, 5, 0, 3, -1]`. Не копируйте пример: сначала напишите шаги словами, затем код.

<details>
<summary>Решение без функции</summary>

```js
const numbers = [-2, 5, 0, 3, -1];
let positiveSum = 0;

for (const number of numbers) {
  if (number > 0) {
    positiveSum += number;
  }
}

console.log(positiveSum); // 8
```

</details>

## Типичные ошибки

- условие `index <= array.length` обращается к несуществующему элементу;
- счётчик не изменяется, и цикл не заканчивается;
- аккумулятор создаётся внутри цикла и сбрасывается на каждой итерации;
- в `for...of` значение принимают за индекс;
- результат выводится внутри цикла, хотя нужен один итог после обхода.
