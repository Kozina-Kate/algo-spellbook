Переменная связывает понятное имя со значением. Благодаря имени результат можно использовать позже, а код начинает описывать смысл действий.

## Объявление переменной

```js
const price = 120;
let total = 0;
```

Разберём первую строку:

- `const` объявляет переменную, которую нельзя направить на другое значение;
- `price` — придуманное нами имя;
- `=` — оператор присваивания: справа вычисляется значение и сохраняется под именем слева;
- `120` — число;
- `;` завершает инструкцию.

`let` используют, когда значение должно изменяться.

```js
let score = 0;
score = 10; // новое значение той же переменной
score = score + 5;
console.log(score); // 15
```

В последней операции сначала читается старое значение `score`, к нему прибавляется `5`, затем результат снова сохраняется в `score`.

:::tip
Начинайте с `const`. Выбирайте `let`, только когда ниже действительно есть новое присваивание.
:::

## Основные типы значений

Для первых задач нужны пять типов.

```js
const count = 7;          // number — число
const title = "Алгоритм"; // string — строка
const ready = true;       // boolean — true или false
const answer = null;      // намеренно нет значения
let result;               // значение пока не задано: undefined
```

Узнать тип помогает встроенная операция `typeof`:

```js
console.log(typeof count); // "number"
console.log(typeof title); // "string"
console.log(typeof ready); // "boolean"
```

`typeof` — оператор, а не функция: круглые скобки ему не обязательны.

## Число и строка — не одно и то же

```js
console.log(2 + 3);     // 5
console.log("2" + "3"); // "23"
console.log("2" + 3);   // "23"
```

Если хотя бы одна сторона `+` — строка, JavaScript может выполнить склеивание вместо сложения. Поэтому в алгоритмических задачах важно понимать тип входных данных.

Для преобразования используют функции `Number` и `String`:

```js
const text = "42";
const number = Number(text);

console.log(number + 1); // 43
console.log(String(15)); // "15"
```

`Number(text)` получает строку и возвращает число, если преобразование возможно. `String(15)` возвращает текстовое представление числа.

## Имена переменных

Хорошее имя отвечает на вопрос «что здесь хранится?».

```js
const x = 5;             // смысл неизвестен
const positiveCount = 5; // понятно: количество положительных значений
```

В JavaScript обычно используют `camelCase`: первое слово со строчной буквы, следующие — с заглавной: `currentSum`, `leftIndex`.

## Сквозная задача: Sum of positive

В курсе мы по частям соберём решение существующей задачи [Sum of positive на Codewars](https://www.codewars.com/kata/5715eaedb436cf5606000381/javascript): для набора чисел нужно получить сумму положительных значений. Сейчас нам важны только данные и переменная результата.

```js
const numbers = [1, -4, 7, 12]; // набор входных чисел
let positiveSum = 0;             // сюда позже будем накапливать сумму

console.log(numbers);
console.log(positiveSum);
```

Квадратные скобки создают массив — упорядоченный набор значений. Подробно массивы разберём в шестом уроке. Пока воспринимайте `numbers` как одну коробку с несколькими числами.

## Предскажите результат

```js
let value = 8;
value = value * 2;
const label = "Ответ: " + value;
console.log(label);
```

<details>
<summary>Ответ</summary>

`value` сначала равен `8`, затем `16`. Строка `"Ответ: "` склеивается с числом, поэтому вывод будет `Ответ: 16`.

</details>

## Практика

Откройте публичную задачу [Opposite number на Codewars](https://www.codewars.com/kata/56dec885c54a926dcd001095). Она просит вернуть число с противоположным знаком. Пока не обязательно оформлять функцию: проверьте идею на переменной.

```js
const number = 12;
const opposite = /* замените комментарий выражением */;
console.log(opposite); // ожидаем -12
```

<details>
<summary>Решение</summary>

```js
const number = 12;
const opposite = -number;
console.log(opposite); // -12
```

Унарный минус `-number` меняет знак числового значения. `const` подходит обеим переменным, потому что ни одна из них не переназначается.

</details>

## Типичные ошибки

- пытаться повторно присвоить значение переменной с `const`;
- путать присваивание `=` со сравнением `===`;
- складывать число со строкой и неожиданно получать текст;
- использовать имя до объявления;
- писать непонятные имена вроде `a1`, когда переменная имеет конкретный смысл.
