## Исходная задача

В [Missing Number](https://leetcode.com/problems/missing-number/) дан массив `numbers`, содержащий `n` различных чисел из диапазона `[0, n]`. В диапазоне отсутствует ровно одно число. Его нужно вернуть.

Примеры:

```text
[3, 0, 1] → 2
[0, 1] → 2
[9, 6, 4, 2, 3, 5, 7, 0, 1] → 8
```

## Шаг 1. Что является входом

Вход — один массив чисел.

```js
function missingNumber(numbers) {
  // numbers — входной массив
}
```

Имя параметра может отличаться от имени на платформе. Важно не название, а договорённость: при каждом вызове внутри `numbers` будет массив.

## Шаг 2. Что нужно вернуть

Результат — одно число, а не индекс и не новый массив.

```js
function missingNumber(numbers) {
  const answer = 0; // пока только место для будущего ответа
  return answer;
}
```

`console.log` не заменяет `return`: проверяющая система вызывает функцию и сравнивает возвращённое значение.

## Шаг 3. Какие факты гарантированы

Из условия известны четыре важных факта:

1. Длина массива равна `n`.
2. Возможные значения идут от `0` до `n` включительно.
3. Все элементы различны.
4. Пропущено ровно одно число.

Если длина массива равна `3`, полный диапазон содержит четыре числа: `0`, `1`, `2`, `3`. Одного из них в массиве нет.

:::caution
Не добавляйте гарантий от себя. В условии не сказано, что массив отсортирован. Пример `[3, 0, 1]` прямо показывает произвольный порядок.
:::

## Шаг 4. Ограничения

В исходной задаче `n` находится между `1` и `10⁴`. Ограничение пока не диктует конкретное решение, но предупреждает: количество данных не фиксировано и может быть намного больше примера.

Ограничения отвечают на вопросы:

- какие значения допустимы;
- может ли вход быть пустым;
- встречаются ли отрицательные числа;
- возможны ли повторы;
- насколько большим бывает вход.

## Шаг 5. Примеры не являются полным условием

Пример помогает понять правило, но не перечисляет все случаи.

```text
[1] → 0
[0] → 1
[2, 0] → 1
```

Первые два случая особенно важны: пропущенное число может находиться в начале или в конце диапазона.

## Записываем контракт

```text
Название: missingNumber
Получает: массив numbers из n различных целых чисел
Диапазон значений: от 0 до n включительно
Гарантия: отсутствует ровно одно число
Возвращает: отсутствующее число
Вход менять не требуется
```

Такой блок отделяет задачу от конкретного синтаксиса. По нему уже можно проверять будущий код.

## Проверьте понимание

Для входа `[4, 2, 1, 0]` ответьте без решения:

1. Чему равно `n`?
2. Какие числа входят в полный диапазон?
3. Какой тип значения должна вернуть функция?
4. Можно ли считать вход отсортированным?

<details>
<summary>Ответ</summary>

`n` равно `4`, потому что в массиве четыре элемента. Полный диапазон: `0`, `1`, `2`, `3`, `4`. Функция возвращает одно число. Считать массив отсортированным нельзя. Пропущенное число — `3`, но способ поиска мы выберем в следующем занятии.
