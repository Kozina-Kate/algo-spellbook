**Научитесь превращать условие задачи в понятный работающий код.** Algo Spellbook подходит и тем, кто только начинает программировать, и тем, кто уже знает основы JavaScript, но хочет системно разобраться в алгоритмах.

Курс не требует предварительного знания алгоритмов. Новые понятия вводятся постепенно: от переменных, условий и циклов до графов и динамического программирования.

## С чего начать

Выберите маршрут по своему текущему уровню. Если сомневаетесь, пройдите короткую [самопроверку](./nachat-obuchenie/) — она нужна только для выбора стартовой главы.

### Я начинаю программировать с нуля

Начните с маршрута [JavaScript с нуля](./javascript-s-nulya/). Сначала вы научитесь читать и писать небольшие программы, работать с функциями, массивами и объектами. После этого перейдёте к сложности алгоритмов и типовым способам решения задач.

**Подходит, если:** слова `const`, `return`, `for` или `array` пока незнакомы либо вы узнаёте их, но не можете самостоятельно написать функцию.

### Я уже знаю основы JavaScript

Начните со [сложности алгоритмов](./slozhnost-algoritmov/), а затем изучите [структуры данных и стоимость операций](./struktury-dannyh-v-js/).

**Подходит, если:** вы можете написать функцию, использовать условие и цикл, пройти по массиву и вернуть результат.

:::tip
Выбор маршрута не закрывает другие страницы. Базовые уроки можно пропускать, а к справочным материалам — возвращаться в любой момент.
:::

## Как устроено обучение

Курс соединяет два навыка, которые нужно развивать вместе:

1. **Выражать мысль кодом.** Переменные, условия, циклы, функции и структуры данных.
2. **Находить способ решения.** Разбор условия, простое решение, поиск лишней работы и выбор подходящего алгоритмического паттерна.

Внутри уроков используется один и тот же цикл:

```text
Понять идею → разобрать пример → предсказать результат
→ запустить код → изменить его → решить задачу самостоятельно
```

Каждый алгоритмический разбор включает условие, ход мысли, код с комментариями, объяснение использованных конструкций, оценку времени и памяти, типичные ошибки и задачи для закрепления.
