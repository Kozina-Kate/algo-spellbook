Условие позволяет программе выбрать действие в зависимости от данных. Это первая конструкция, с которой код перестаёт быть одной неизменной последовательностью.

## Арифметические операторы

```js
const sum = 8 + 3;       // 11
const difference = 8 - 3; // 5
const product = 8 * 3;   // 24
const quotient = 8 / 2;  // 4
const remainder = 8 % 3; // 2
```

Оператор `%` возвращает остаток от деления. Он часто помогает определить чётность: у чётного числа остаток от деления на `2` равен нулю.

## Сравнение возвращает boolean

```js
console.log(7 > 3);   // true
console.log(7 < 3);   // false
console.log(7 === 7); // true
console.log(7 !== 7); // false
```

- `===` — строго равно;
- `!==` — строго не равно;
- `<`, `>`, `<=`, `>=` — сравнение порядка.

В курсе используем строгое равенство `===`. Оператор `==` выполняет неявные преобразования типов, из-за которых `0 == "0"` даёт `true`. Для новичка такое поведение только скрывает ошибки.

## if и else

```js
const temperature = -2;

if (temperature < 0) {
  console.log("мороз");
} else {
  console.log("не мороз");
}
```

Как выполняется код:

1. Вычисляется выражение `temperature < 0`.
2. Если получилось `true`, выполняется первый блок `{ ... }`.
3. Если получилось `false`, выполняется блок после `else`.
4. После выбранного блока программа продолжает работу ниже.

Фигурные скобки объединяют несколько инструкций в один **блок**.

## Несколько вариантов

```js
const number = 0;

if (number > 0) {
  console.log("положительное");
} else if (number < 0) {
  console.log("отрицательное");
} else {
  console.log("ноль");
}
```

Проверки идут сверху вниз. После первого подходящего условия остальные ветки пропускаются.

## Логические операторы

```js
const age = 20;
const hasTicket = true;

console.log(age >= 18 && hasTicket); // true: обе части истинны
console.log(age < 18 || hasTicket);  // true: истинна хотя бы одна часть
console.log(!hasTicket);             // false: логическое отрицание
```

- `&&` означает «и»;
- `||` означает «или»;
- `!` меняет `true` на `false` и наоборот.

Если выражение становится длинным, вынесите части в переменные с понятными именами.

## Сквозная задача: выбираем положительные числа

Продолжим [Sum of positive](https://www.codewars.com/kata/5715eaedb436cf5606000381/javascript). Условие, которое определяет нужный элемент:

```js
const number = -4;

if (number > 0) {
  console.log("добавить к сумме");
} else {
  console.log("пропустить");
}
```

Пока проверяется одно число. В следующем уроке цикл применит ту же проверку ко всему массиву.

## Предскажите результат

```js
const number = 14;

if (number % 2 === 0 && number > 10) {
  console.log("подходит");
} else {
  console.log("не подходит");
}
```

<details>
<summary>Ответ</summary>

`14 % 2` равно `0`, поэтому первая часть истинна. `14 > 10` тоже истинно. Оператор `&&` получает два `true`, поэтому выводится `подходит`.

</details>

## Практика: Even or Odd

Используйте существующую задачу [Even or Odd на Codewars](https://www.codewars.com/kata/53da3dbb4a5168369a0000fe): по целому числу нужно выбрать строку `"Even"` для чётного или `"Odd"` для нечётного.

Допишите только условие:

```js
const number = 9;

if (/* условие чётности */) {
  console.log("Even");
} else {
  console.log("Odd");
}
```

<details>
<summary>Решение</summary>

```js
const number = 9;

if (number % 2 === 0) {
  console.log("Even");
} else {
  console.log("Odd");
}
```

`number % 2` находит остаток от деления на два. Строгое сравнение проверяет, равен ли остаток нулю.

</details>

## Типичные ошибки

- написать `=` вместо `===` в условии;
- забыть фигурную или круглую скобку;
- перепутать `&&` и `||`;
- сравнивать число со строкой;
- написать несколько независимых `if`, когда варианты должны исключать друг друга.

## Проверьте себя

- [ ] Я могу получить остаток от деления через `%`.
- [ ] Я понимаю, что сравнение возвращает `true` или `false`.
- [ ] Я могу записать две взаимоисключающие ветки через `if / else`.
- [ ] Я различаю присваивание `=` и сравнение `===`.
- [ ] Я могу соединить две проверки операторами `&&` или `||`.
