## Быстрый шаблон программы

```js
function solve(numbers) {
  let result = 0;

  for (const number of numbers) {
    if (number > 0) {
      result += number;
    }
  }

  return result;
}

console.log(solve([-2, 3, 5])); // 8
```

- `function solve(numbers)` объявляет функцию и её параметр;
- `let result = 0` создаёт изменяемый аккумулятор;
- `for...of` берёт значения массива по одному;
- `if` выполняет блок только при истинном условии;
- `result += number` обновляет накопленный результат;
- `return` отдаёт ответ из функции;
- `console.log` показывает результат для проверки.

## Переменные и типы

```js
const limit = 10;          // значение не будем переназначать
let count = 0;             // значение будет изменяться
const title = "graph";     // string
const found = false;       // boolean
const missing = null;      // намеренно нет значения
let answer;                // undefined: значение не присвоено
```

Используйте `const` по умолчанию. Выбирайте `let`, только если переменная получит новое значение, например счётчик внутри цикла.

| Тип | Пример | Для чего нужен в задачах |
| --- | --- | --- |
| `number` | `42`, `-3`, `2.5` | числа, индексы, суммы |
| `string` | `"code"` | текст и отдельные символы |
| `boolean` | `true`, `false` | результат проверки, флаг |
| `null` | `let node = null` | намеренное отсутствие узла |
| `undefined` | `map.get("x")` | значение не найдено или не задано |

`typeof value` возвращает название типа. Для массива используйте `Array.isArray(value)`, потому что `typeof []` возвращает строку `"object"`.

`Infinity` удобно использовать как начальное «бесконечно большое» значение при поиске минимума. `Number.MAX_SAFE_INTEGER` — наибольшее целое, с которым обычный тип `number` сохраняет точность; для целых чисел за этой границей нужен `BigInt`.

## Операторы

| Запись | Значение |
| --- | --- |
| `a + b`, `a - b`, `a * b`, `a / b` | арифметика |
| `a % b` | остаток от деления |
| `count += 1` | прибавить и сохранить |
| `count -= 1` | вычесть и сохранить |
| `a === b`, `a !== b` | строгое равенство и неравенство |
| `a < b`, `a <= b`, `a > b`, `a >= b` | сравнение чисел |
| `left && right` | истинны обе проверки |
| `left || right` | истинна хотя бы одна проверка |
| `!condition` | логическое отрицание |
| `value ?? fallback` | взять запасное значение только для `null` или `undefined` |

Для сравнений используйте `===` и `!==`. Оператор `=` присваивает значение, а не сравнивает.

## Условия

```js
if (score > best) {
  best = score;
} else if (score === best) {
  count += 1;
} else {
  console.log("Результат меньше лучшего");
}
```

Короткий выбор между двумя значениями можно записать тернарным оператором:

```js
const label = value >= 0 ? "positive" : "negative";
```

| Нужно проверить | Запись |
| --- | --- |
| число чётное | `number % 2 === 0` |
| индекс допустим | `index >= 0 && index < array.length` |
| массив пуст | `array.length === 0` |
| значение отсутствует | `value === undefined` или `value === null` |

## Циклы

### Значения массива

```js
for (const value of values) {
  console.log(value);
}
```

Используйте `for...of`, когда позиция элемента не нужна.

### Индексы массива

```js
for (let index = 0; index < values.length; index += 1) {
  console.log(index, values[index]);
}
```

Последний допустимый индекс равен `values.length - 1`, поэтому условие содержит `<`, а не `<=`.

### Пока условие истинно

```js
let left = 0;
let right = values.length - 1;

while (left < right) {
  left += 1;
  right -= 1;
}
```

В `while` хотя бы одна переменная должна приближать условие к `false`, иначе цикл станет бесконечным.

### Прервать или пропустить шаг

```js
for (const value of values) {
  if (value < 0) continue; // перейти к следующему значению
  if (value === target) break; // полностью закончить цикл
}
```

## Функции

```js
function sum(a, b) {
  const result = a + b;
  return result;
}

const answer = sum(2, 3);
```

- `a` и `b` — параметры объявления;
- `2` и `3` — аргументы вызова;
- `result` существует только внутри функции;
- `return` заканчивает вызов и отдаёт значение;
- если `return` отсутствует, функция возвращает `undefined`.

Короткая функция-стрелка часто передаётся в метод:

```js
const doubled = numbers.map((number) => number * 2);
```

`(number) => number * 2` принимает число и возвращает его удвоенное значение.

## Массивы

```js
const values = [10, 20, 30];

values[0];                  // 10
values.length;              // 3
values[values.length - 1];  // 30
```

### Основные методы массивов

| Запись | Результат | Меняет массив | Обычно по времени |
| --- | --- | --- | --- |
| `arr.push(value)` | добавляет в конец, возвращает длину | да | O(1)* |
| `arr.pop()` | удаляет и возвращает последний | да | O(1) |
| `arr.shift()` | удаляет и возвращает первый | да | O(n) |
| `arr.unshift(value)` | добавляет в начало | да | O(n) |
| `arr.slice(start, end)` | копирует участок без `end` | нет | O(k) |
| `arr.splice(start, count)` | удаляет или вставляет внутри | да | O(n) |
| `arr.includes(value)` | возвращает `true` или `false` | нет | O(n) |
| `arr.indexOf(value)` | возвращает индекс или `-1` | нет | O(n) |
| `arr.reverse()` | разворачивает порядок | да | O(n) |
| `arr.join(separator)` | собирает строку | нет | O(n) |
| `arr.concat(other)` | создаёт объединённый массив | нет | O(n + m) |

\* Добавление в конец имеет амортизированную O(1): отдельное расширение внутреннего хранилища бывает дороже, но редко.

### Создание массивов

```js
const zeros = new Array(5).fill(0);
const indexes = Array.from({ length: 5 }, (_, index) => index);
const copy = values.slice();
```

Для вложенных массивов не используйте `new Array(rows).fill([])`: все строки будут ссылаться на один массив. Создавайте их отдельно:

```js
const matrix = Array.from(
  { length: rows },
  () => new Array(columns).fill(0),
);
```

### Раскрытие и деструктуризация

```js
const copy = [...values];          // раскрыть элементы в новый массив
const combined = [...left, ...right];
const [first, second] = values;    // взять элементы по позициям
const [key, count] = pair;         // разобрать пару из Map
```

Оператор `...` здесь раскрывает значения коллекции. Квадратные скобки слева от `=` разбирают массив по позициям и сохраняют элементы в отдельные переменные.

### Методы с функцией

| Метод | Что возвращает | Меняет массив | Обычно по времени |
| --- | --- | --- | --- |
| `arr.map(fn)` | новый массив результатов | нет | O(n) |
| `arr.filter(fn)` | новый массив подходящих элементов | нет | O(n) |
| `arr.find(fn)` | первое подходящее значение | нет | O(n) |
| `arr.findIndex(fn)` | индекс или `-1` | нет | O(n) |
| `arr.every(fn)` | подходят ли все элементы | нет | O(n) |
| `arr.forEach(fn)` | ничего (`undefined`) | нет* | O(n) |
| `arr.reduce(fn, start)` | одно накопленное значение | нет | O(n) |

\* Сам `forEach` не меняет массив, но переданная функция может это сделать. В алгоритмах обычный цикл часто легче отлаживать, чем цепочку методов.

## Строки

```js
const text = "algorithm";

text[0];          // "a"
text.length;      // 9
text.slice(0, 4); // "algo"
```

Строки неизменяемы: `text[0] = "A"` не заменит символ. Нужно создать новую строку.

| Запись | Что возвращает | Обычно по времени |
| --- | --- | --- |
| `text.slice(start, end)` | часть строки без `end` | O(k) |
| `text.substring(start, end)` | часть строки | O(k) |
| `text.includes(part)` | есть ли подстрока | до O(n · m) |
| `text.indexOf(part)` | позиция или `-1` | до O(n · m) |
| `text.split(separator)` | массив частей | O(n) |
| `text.toLowerCase()` | новую строку в нижнем регистре | O(n) |
| `text.trim()` | строку без пробелов по краям | O(n) |
| `text.repeat(count)` | повторённую строку | O(n · count) |
| `letters.join("")` | строку из массива | O(n) |

Практический разворот строки:

```js
const reversed = text.split("").reverse().join("");
```

### Коды символов и шаблонная строка

```js
const code = "c".charCodeAt(0);       // 99
const letter = String.fromCharCode(99); // "c"
const index = code - "a".charCodeAt(0); // 2

const message = `Индекс буквы: ${index}`;
```

`charCodeAt(index)` возвращает числовой код символа. `String.fromCharCode(code)` выполняет обратное преобразование. Вычитание кода `"a"` превращает строчные латинские буквы в индексы `0...25`. Запись в обратных кавычках подставляет значение выражения из `${...}` в строку.

## Объекты

```js
const counts = {};
const key = "a";

counts[key] = (counts[key] ?? 0) + 1;
console.log(counts[key]); // 1
```

- `object.name` — доступ по заранее известному имени;
- `object[key]` — доступ по ключу из переменной;
- `Object.keys(object)` — массив собственных ключей;
- `Object.values(object)` — массив значений;
- `Object.entries(object)` — массив пар `[key, value]`.

Для произвольных ключей в алгоритмических задачах чаще выбирайте `Map`: его API явно отделяет ключи от свойств объекта.

## Map

```js
const counts = new Map();

counts.set("a", 2);
counts.get("a");    // 2
counts.has("a");    // true
counts.delete("a");
counts.size;         // 0 — это свойство, не функция
```

| Операция | Что делает | В среднем |
| --- | --- | --- |
| `map.set(key, value)` | записывает или заменяет пару | O(1) |
| `map.get(key)` | возвращает значение или `undefined` | O(1) |
| `map.has(key)` | проверяет ключ | O(1) |
| `map.delete(key)` | удаляет пару | O(1) |
| `map.clear()` | удаляет все пары | O(n) |
| `map.size` | возвращает число ключей | O(1) |

Перебор карты:

```js
for (const [key, value] of counts) {
  console.log(key, value);
}

for (const key of counts.keys()) { /* ключи */ }
for (const value of counts.values()) { /* значения */ }
for (const pair of counts.entries()) { /* пары [ключ, значение] */ }
```

`keys()`, `values()` и `entries()` возвращают итерируемые последовательности. Их можно обходить через `for...of` или превратить в массив оператором `...`: `[...counts.values()]`.

Частотный словарь:

```js
counts.set(value, (counts.get(value) ?? 0) + 1);
```

## Set

```js
const seen = new Set();

seen.add(5);
seen.has(5);    // true
seen.delete(5);
seen.size;      // 0
```

| Операция | Что делает | В среднем |
| --- | --- | --- |
| `set.add(value)` | добавляет уникальное значение | O(1) |
| `set.has(value)` | проверяет наличие | O(1) |
| `set.delete(value)` | удаляет значение | O(1) |
| `set.size` | возвращает число значений | O(1) |

Удаление повторов создаёт новый массив:

```js
const unique = [...new Set(values)];
```

## Сортировка

`sort` изменяет исходный массив. Если исходный порядок нужен позже, сначала сделайте копию.

```js
const ascending = [...numbers].sort((a, b) => a - b);
const descending = [...numbers].sort((a, b) => b - a);
const words = [...names].sort((a, b) => a.localeCompare(b));
const pairs = [...intervals].sort((a, b) => a[0] - b[0]);
```

Компаратор возвращает:

- отрицательное число, если `a` должно стоять раньше `b`;
- положительное число, если `b` должно стоять раньше `a`;
- `0`, если элементы равны для этой сортировки.

Без компаратора числа сравниваются как строки: `[10, 2].sort()` даст `[10, 2]`, а не `[2, 10]`. Типичная сложность встроенной сортировки — O(n log n), дополнительная память зависит от движка JavaScript.

## Math

| Запись | Результат |
| --- | --- |
| `Math.min(a, b)` | меньшее число |
| `Math.max(a, b)` | большее число |
| `Math.abs(value)` | модуль числа |
| `Math.floor(value)` | округление вниз |
| `Math.ceil(value)` | округление вверх |
| `Math.round(value)` | округление до ближайшего целого |
| `Math.trunc(value)` | удаление дробной части |
| `Math.sqrt(value)` | квадратный корень |

Минимум или максимум массива:

```js
const minimum = Math.min(...numbers);
const maximum = Math.max(...numbers);
```

Для очень больших массивов оператор `...` может превысить лимит аргументов. Надёжный вариант — пройти массив циклом.

## Стоимость операций

| Что делаем | Подходящая структура | Обычно |
| --- | --- | --- |
| читаем элемент по индексу | `Array`, `String` | O(1) |
| добавляем или удаляем с конца | `Array` | O(1)* |
| добавляем или удаляем с начала | `Array` | O(n) |
| ищем значение перебором | `Array`, `String` | O(n) |
| проверяем сохранённый ключ | `Map`, `Set` | O(1) в среднем |
| копируем массив или строку длины n | новая коллекция | O(n) |
| сортируем n элементов | `Array.sort` | обычно O(n log n) |

Самая частая скрытая ошибка — линейная операция внутри линейного цикла:

```js
for (const value of first) {       // O(n)
  if (second.includes(value)) {    // O(m) на каждом шаге
    // вместе O(n · m)
  }
}
```

Если нужен только быстрый вопрос «встречалось ли значение?», один раз создайте `Set` и проверяйте через `has`.

Подробные объяснения и оговорки собраны в главах [«Сложность алгоритмов»](../slozhnost-algoritmov/) и [«Структуры данных в JavaScript»](../struktury-dannyh-v-js/).

## Быстрая отладка

```js
console.log({ index, value, result });
```

1. Запишите ожидаемый ответ до запуска.
2. Найдите первую строку, после которой состояние стало неверным.
3. Проверьте пустой ввод, один элемент, повторения и крайние значения.
4. Уберите временные `console.log` из окончательного решения.

Для небольших учебных массивов удобно сравнить содержимое:

```js
console.log(JSON.stringify(actual));
console.log(JSON.stringify(expected));
```

`JSON.stringify` создаёт строковое представление. Это удобная отладочная подсказка, но не универсальная проверка равенства любых объектов.

Если JavaScript показывает ошибку, прочитайте её тип, сообщение и номер строки. Подробный маршрут — в уроке [«Ошибки, отладка и тесты»](../js-08-oshibki-i-otladka/).

## Скелет решения задачи

```js
/**
 * @param {number[]} numbers
 * @returns {number}
 */
function solve(numbers) {
  // 1. Создаём состояние.
  let answer = 0;

  // 2. Обрабатываем входные данные.
  for (const number of numbers) {
    answer += number;
  }

  // 3. Возвращаем результат нужного типа.
  return answer;
}
```

Перед кодом сформулируйте вход, результат и шаги обычными словами. Затем проверьте функцию минимум на обычном и краевом примерах. Полный процесс — в блоке [«От условия к коду»](../ot-usloviya-k-kodu/).

## Как выбрать инструмент

| Формулировка мысли | Первая конструкция для проверки |
| --- | --- |
| «для каждого элемента» | `for...of` |
| «нужна позиция или сосед» | индексный `for` |
| «повторять, пока границы не встретятся» | `while` |
| «если выполняется условие» | `if` |
| «накопить один ответ» | переменная-аккумулятор |
| «собрать новый порядок значений» | новый массив и `push` |
| «сколько раз встречается» | `Map` |
| «встречалось ли раньше» | `Set` |
| «обрабатывать по порядку величины» | `sort` с компаратором |

:::tip[Главное правило]
Выбирайте конструкцию по смыслу шага, а не по тому, какой код короче. Сначала добейтесь понятного правильного решения, затем оценивайте и ускоряйте его.
:::
