Эта самопроверка не является экзаменом. Она помогает не перепрыгнуть через необходимые основы и не тратить время на уже знакомый материал.

## Проверьте себя

Ответьте «да», только если можете выполнить действие самостоятельно, без поиска готового кода.

1. Понимаю разницу между числом, строкой и логическим значением.
2. Могу объяснить, чем `const` отличается от `let`.
3. Могу написать условие с `if` и `else`.
4. Могу использовать цикл `for` или `while`.
5. Могу написать функцию с параметрами и `return`.
6. Могу пройти циклом по всем элементам массива.
7. Понимаю, что означают индекс и `array.length`.
8. Могу добавить значение в массив и прочитать свойство объекта.
9. Знаю, для чего применяются `Map` и `Set`.
10. Могу найти простую ошибку в коде с помощью сообщения об ошибке или `console.log`.

## Выберите результат

### 0–4 ответа «да»

Начните с [JavaScript с нуля](../javascript-s-nulya/). Это основной маршрут для новичка: он последовательно объясняет синтаксис и сразу связывает его с решением небольших задач.

### 5–7 ответов «да»

Тоже откройте [JavaScript с нуля](../javascript-s-nulya/), но проходите знакомые темы быстрее. В конце каждого урока будет чеклист: если все пункты понятны, переходите дальше.

### 8–10 ответов «да»

Можно начинать со [сложности алгоритмов](../slozhnost-algoritmov/). Если в примере встретится незнакомая конструкция JavaScript, вернитесь к соответствующему базовому уроку.

:::note
Количество ответов «да» не характеризует способности к программированию. Оно показывает только подходящую точку входа прямо сейчас.
:::

## Два маршрута, одна цель

```text
Начинаю с нуля → Основы JavaScript ─┐
                                    ├→ Алгоритмы → Практика паттернов
Знаю основы JS → Сложность и данные ┘
```

На алгоритмическом маршруте обе группы изучают один и тот же материал. Различается только подготовка перед ним.

## Как заниматься

- Проходите не больше одной новой темы за занятие.
- Перед запуском примера попробуйте предсказать результат.
- После разбора закройте решение и восстановите его самостоятельно.
- Записывайте ошибки своими словами: это станет персональным справочником.
- Возвращайтесь к пройденной задаче через несколько дней.

:::tip
Лучше уверенно освоить один цикл и одну функцию, чем за день прочитать десять глав и не написать код самостоятельно.
:::
