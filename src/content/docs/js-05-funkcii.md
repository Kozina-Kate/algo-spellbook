Функция объединяет несколько инструкций под одним именем. Её можно вызывать с разными входными данными и получать результат.

Алгоритмические платформы обычно уже передают входные данные в функцию. Ваша задача — написать её тело и вернуть ответ.

:::note[Перед началом]
**Урок 5 из 9 · 25–30 минут**

**Нужно знать:** переменные, условия и циклы. **После урока:** сможете объявить функцию, передать аргументы и вернуть вычисленный результат.
:::

## Объявление функции

```js
function multiply(a, b) {
  const product = a * b;
  return product;
}
```

Разбор записи:

- `function` сообщает, что создаётся функция;
- `multiply` — имя функции;
- `a` и `b` — параметры, то есть имена входных значений;
- `{ ... }` — тело функции;
- `return product` завершает функцию и отдаёт результат наружу.

## Вызов функции

```js
const answer = multiply(4, 6);
console.log(answer); // 24
```

`4` и `6` — **аргументы** конкретного вызова. При выполнении `a` получает `4`, а `b` — `6`.

Объявление функции само по себе не запускает тело. Код внутри выполняется только при вызове `multiply(...)`.

## return не равен console.log

```js
function addWrong(a, b) {
  console.log(a + b);
}

const result = addWrong(2, 3);
console.log(result); // undefined
```

Первый `console.log` покажет `5`, но функция ничего не вернула. Поэтому переменная `result` получает `undefined`.

Правильный вариант:

```js
function add(a, b) {
  return a + b;
}

const result = add(2, 3);
console.log(result); // 5
```

`console.log` показывает значение человеку. `return` передаёт значение в другую часть программы или проверяющей системе.

## return сразу завершает функцию

```js
function describeNumber(number) {
  if (number > 0) {
    return "positive";
  }

  return "not positive";
}
```

Если число положительное, первая команда `return` завершит вызов. До последней строки выполнение не дойдёт.

## Локальные переменные

```js
function square(number) {
  const result = number * number;
  return result;
}

console.log(square(5)); // 25
console.log(result);    // ReferenceError
```

Переменная `result` создана внутри функции и видна только там. Это **локальная область видимости**. Локальные переменные разных вызовов не мешают друг другу.

## Собираем сквозную задачу полностью

Готовое решение [Sum of positive](https://www.codewars.com/kata/5715eaedb436cf5606000381/javascript):

```js
function positiveSum(numbers) {
  let sum = 0;

  for (const number of numbers) {
    if (number > 0) {
      sum += number;
    }
  }

  return sum;
}

console.log(positiveSum([1, -4, 7, 12])); // 20
console.log(positiveSum([]));             // 0
```

### Разбор функций и конструкций

- `positiveSum(numbers)` получает один параметр — массив чисел.
- `let sum = 0` создаёт аккумулятор внутри каждого вызова.
- `for...of` последовательно читает элементы.
- `if` выбирает только числа больше нуля.
- `sum += number` обновляет аккумулятор.
- `return sum` возвращает итог после завершения цикла.
- `console.log` нужен только в наших проверочных вызовах и не является частью решения.

Для пустого массива цикл не выполнится ни разу, поэтому функция вернёт начальное значение `0`.

## Предскажите результат

```js
function change(value) {
  value += 3;
  return value * 2;
}

const number = 4;
console.log(change(number));
console.log(number);
```

<details>
<summary>Ответ</summary>

Первый вывод — `14`: внутри функции `4 + 3`, затем умножение на `2`. Второй — `4`: параметр `value` является отдельной локальной переменной, исходная числовая переменная не изменилась.

</details>

## Измените код

Добавьте функции `positiveSum` второй параметр `minimum` и суммируйте только числа больше него. Проверьте `positiveSum([1, 5, 10], 4)`: ожидаемый ответ — `15`.

## Самостоятельная практика: Multiply

Решите существующую задачу [Multiply на Codewars](https://www.codewars.com/kata/50654ddff44f800200000004/javascript): функция получает два числа и должна вернуть их произведение.

```js
function multiply(a, b) {
  // верните результат
}
```

<details>
<summary>Решение</summary>

```js
function multiply(a, b) {
  return a * b;
}
```

`a * b` вычисляет произведение. `return` сразу отдаёт его вызывающему коду; дополнительная переменная не обязательна.

</details>

## Типичные ошибки

- написать функцию, но ни разу её не вызвать;
- вывести ответ через `console.log`, но забыть `return`;
- поставить `return` внутри цикла слишком рано;
- обращаться снаружи к локальной переменной;
- перепутать параметры объявления и аргументы вызова.
