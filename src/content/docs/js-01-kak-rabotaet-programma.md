Программа — это последовательность инструкций для компьютера. JavaScript обычно выполняет их сверху вниз, одну за другой. Пока не нужно понимать устройство браузера или движка: достаточно научиться читать порядок действий.

:::note[Перед началом]
**Урок 1 из 9 · 15–20 минут**

**Нужно знать:** ничего. **После урока:** сможете запустить несколько инструкций, предсказать порядок вывода и использовать комментарии.
:::

## Значение, выражение и инструкция

**Значение** — конкретные данные: число `7`, строка `"кот"`, логическое значение `true`.

**Выражение** — запись, которую JavaScript может вычислить. Например, `2 + 3` превращается в значение `5`.

**Инструкция** — законченное действие. В конце инструкции в этом курсе ставим `;`. JavaScript часто умеет добавить точку с запятой сам, но явная запись делает границы действий заметнее.

```js
2 + 3; // выражение вычислится, но результат нигде не сохранится
console.log(2 + 3); // в консоли появится 5
```

`console.log(...)` просит среду выполнения показать переданное значение. Это средство наблюдения: оно помогает увидеть, что делает программа.

## Читаем программу сверху вниз

Сначала попробуйте предсказать вывод, не запуская код.

```js
console.log("начало"); // первая инструкция
console.log(4 + 1);    // вторая инструкция: сначала вычислится 4 + 1
console.log("конец"); // третья инструкция
```

Результат:

```text
начало
5
конец
```

### Что здесь является функцией

`console.log` — встроенная функция. **Функция** — именованный набор действий. Чтобы вызвать функцию, после имени ставят круглые скобки: `console.log(...)`.

Значение внутри скобок называется **аргументом**. В `console.log(5)` аргумент — число `5`. В `console.log(4 + 1)` сначала вычисляется выражение `4 + 1`, затем полученное число передаётся функции.

## Комментарии

Комментарий предназначен для человека и не выполняется JavaScript.

```js
// Однострочный комментарий продолжается до конца строки.
console.log(10); // комментарий можно поставить после инструкции

/* Такой комментарий
   может занимать несколько строк. */
console.log(20);
```

Комментарии полезны, когда объясняют **зачем** нужен шаг. Пересказывать очевидный код обычно не нужно.

```js
// Хорошо: объясняет смысл числа.
console.log(24 * 60); // количество минут в сутках
```

## Код чувствителен к регистру

`console`, `Console` и `CONSOLE` — разные имена. Правильная встроенная запись — `console.log`.

```js
console.log("работает");
Console.log("ошибка"); // ReferenceError: Console is not defined
```

Сообщение `ReferenceError` означает, что JavaScript не нашёл имя `Console`.

## Предскажите результат

```js
console.log(3 * 4);
// console.log(100);
console.log("3 * 4");
```

<details>
<summary>Ответ</summary>

Сначала появится число `12`. Вторая строка — комментарий, поэтому не выполнится. Затем появится текст `3 * 4`: кавычки превращают содержимое в строку, и умножение не выполняется.

</details>

## Измените код

Возьмите пример выше и:

1. замените умножение сложением;
2. добавьте ещё один `console.log`;
3. временно превратите его в комментарий;
4. сравните предсказанный и фактический вывод.

Здесь нет отдельной алгоритмической задачи: цель — научиться запускать код и наблюдать порядок выполнения. Первая сквозная задача появится в уроке про переменные и будет собираться по частям до урока про функции.

## Самостоятельная практика

Не запуская код, запишите три строки, которые должны появиться в консоли. Затем проверьте себя.

```js
console.log("шаг 1");
console.log(6 / 2);
// console.log("эта строка пропущена");
console.log("шаг " + "3");
```

<details>
<summary>Решение</summary>

```text
шаг 1
3
шаг 3
```

Деление выполняется до вызова `console.log`. Закомментированная инструкция пропускается. Две строки в последней инструкции склеиваются оператором `+`.

</details>

## Типичные ошибки

- написать `console,log` вместо `console.log`;
- забыть закрыть кавычку или круглую скобку;
- ожидать вычисления от текста в кавычках;
- изменить несколько строк сразу и не понимать, какое изменение повлияло на результат.
