## Пять представлений одной задачи

```text
Условие → пример → шаги словами → код → проверки
```

Если переход не получается, вернитесь на одно представление назад. Например, когда непонятен код цикла, пройдите пример руками и запишите состояния переменных.

## Учебная задача: Running Sum of 1d Array

Используем существующую задачу [Running Sum of 1d Array на LeetCode](https://leetcode.com/problems/running-sum-of-1d-array/). Дан массив чисел. В результате на позиции `i` должна находиться сумма элементов от начала массива до позиции `i` включительно.

Пример:

```text
Вход:  [1, 2, 3, 4]
Выход: [1, 3, 6, 10]
```

## Шаг 1. Выделить контракт

**Вход:** один массив чисел `numbers`.

**Выход:** новый массив той же длины.

**Связь:** очередной результат равен предыдущей накопленной сумме плюс текущее число.

Из этого получается заготовка функции:

```js
function runningSum(numbers) {
  // здесь появятся шаги решения
}
```

**Контракт функции** — договорённость о том, какие данные она получает и что возвращает.

## Шаг 2. Пройти пример руками

| Текущее число | Накопленная сумма | Результат |
| ---: | ---: | --- |
| начало | 0 | `[]` |
| 1 | 1 | `[1]` |
| 2 | 3 | `[1, 3]` |
| 3 | 6 | `[1, 3, 6]` |
| 4 | 10 | `[1, 3, 6, 10]` |

Таблица подсказывает две переменные состояния:

- число `sum`, начинающееся с `0`;
- массив `result`, начинающийся пустым.

## Шаг 3. Записать алгоритм словами

1. Создать пустой массив результата.
2. Создать накопленную сумму со значением ноль.
3. Для каждого входного числа прибавить его к сумме.
4. Добавить новую сумму в результат.
5. После цикла вернуть результат.

Если эти шаги понятны, код становится переводом, а не угадыванием.

## Шаг 4. Перевести шаги в JavaScript

```js
function runningSum(numbers) {
  const result = [];
  let sum = 0;

  for (const number of numbers) {
    sum += number;
    result.push(sum);
  }

  return result;
}
```

### Разбор каждой конструкции

- `function runningSum(numbers)` создаёт функцию с одним входным параметром.
- `const result = []` создаёт новый пустой массив. Саму переменную не переназначаем, но добавляем элементы в массив.
- `let sum = 0` создаёт изменяемый аккумулятор.
- `for (const number of numbers)` перебирает входные значения слева направо.
- `sum += number` обновляет накопленную сумму.
- `result.push(sum)` записывает текущее состояние суммы в конец результата.
- `return result` отдаёт готовый массив после полного обхода.

## Предскажите результат

Не запускайте функцию сразу. Пройдите цикл вручную и запишите значения `sum` и `result` после каждой итерации.

```js
console.log(runningSum([2, -1, 3]));
```

<details>
<summary>Ответ</summary>

После первого числа: `sum = 2`, `result = [2]`. После второго: `sum = 1`, `result = [2, 1]`. После третьего: `sum = 4`, `result = [2, 1, 4]`. Именно этот массив будет выведен.

</details>

## Шаг 5. Проверить функцию

```js
console.log(runningSum([1, 2, 3, 4])); // [1, 3, 6, 10]
console.log(runningSum([3]));          // [3]
console.log(runningSum([-2, 5]));      // [-2, 3]
console.log(runningSum([]));           // []
```

Проверки покрывают обычный массив, один элемент, отрицательное число и пустой вход.

## Как сравнить массивы без тестовой библиотеки

Для учебной проверки можно временно превратить массивы в строки JSON:

```js
function checkArray(actual, expected, testName) {
  const actualText = JSON.stringify(actual);
  const expectedText = JSON.stringify(expected);

  if (actualText === expectedText) {
    console.log("✓", testName);
  } else {
    console.log("✗", testName, { actual, expected });
  }
}

checkArray(runningSum([1, 2, 3]), [1, 3, 6], "обычный массив");
checkArray(runningSum([]), [], "пустой массив");
```

`JSON.stringify` возвращает строковое представление массива. Для простых массивов чисел это позволяет сравнить содержимое. Это учебный приём, а не универсальная функция глубокого сравнения любых объектов.

Затем сопоставьте фразы с конструкциями:

| Фраза | JavaScript |
| --- | --- |
| «для каждого элемента» | `for...of` |
| «пока условие истинно» | `while` |
| «если» | `if` |
| «накопить» | `let` и обновление значения |
| «сохранить по ключу» | объект или `Map` |
| «запомнить уникальные» | `Set` |
| «отдать ответ» | `return` |

## Самостоятельная практика

Решите [Running Sum of 1d Array](https://leetcode.com/problems/running-sum-of-1d-array/) ещё раз, не открывая разбор:

1. выпишите контракт;
2. пройдите `[3, 1, 2]` руками;
3. напишите пять шагов словами;
4. восстановите функцию;
5. проверьте минимум три случая.

После этого вернитесь к [Sum of positive](https://www.codewars.com/kata/5715eaedb436cf5606000381/javascript) и также оформите её через контракт, словесные шаги, функцию и проверки.

## Типичные ошибки

- писать цикл до того, как определены вход и выход;
- возвращать результат внутри первой итерации;
- забыть начальное значение аккумулятора;
- изменять входной массив, хотя нужен новый результат;
- проверять только пример из условия;
- пытаться сразу придумать самое короткое решение.
