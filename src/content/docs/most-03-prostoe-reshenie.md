У нас уже есть контракт, ручной пример и псевдокод. Теперь каждая строка программы должна соответствовать одному из словесных шагов.

:::note[Перед началом]
**Занятие 3 из 4 · 25–30 минут**

**Нужно знать:** цикл `for`, условие, `return` и `includes`. **После занятия:** сможете написать и объяснить простое корректное решение.
:::

## Псевдокод перед глазами

```text
для каждого кандидата от 0 до длины массива включительно:
    если кандидата нет во входном массиве:
        вернуть кандидата
```

Не пытайтесь перевести всю запись одним движением. Берите по одной строке.

## Строка 1. Объявляем функцию

```js
function missingNumber(numbers) {
}
```

`numbers` — параметр, в котором во время вызова находится входной массив. Фигурные скобки ограничивают тело функции.

## Строка 2. Перебираем кандидатов

```js
for (let candidate = 0; candidate <= numbers.length; candidate += 1) {
}
```

- `let candidate = 0` задаёт начало диапазона;
- `candidate <= numbers.length` включает число `n`;
- `candidate += 1` переходит к следующему целому числу.

## Строка 3. Проверяем отсутствие

```js
if (!numbers.includes(candidate)) {
}
```

`numbers.includes(candidate)` возвращает `true`, если кандидат присутствует. Оператор `!` меняет значение на противоположное, поэтому тело `if` выполняется только для отсутствующего числа.

## Строка 4. Возвращаем ответ

```js
return candidate;
```

По гарантии отсутствует ровно одно число. Как только оно найдено, дальнейшие проверки не нужны: `return` завершает функцию.

## Полное решение

```js
function missingNumber(numbers) {
  for (
    let candidate = 0;
    candidate <= numbers.length;
    candidate += 1
  ) {
    if (!numbers.includes(candidate)) {
      return candidate;
    }
  }
}
```

Заголовок `for` перенесён на несколько строк только для подробного чтения. Равнозначная компактная запись:

```js
for (let candidate = 0; candidate <= numbers.length; candidate += 1) {
  // тело цикла
}
```

## Трассировка

Для `numbers = [3, 0, 1]`:

| `candidate` | `includes(candidate)` | После `!` | Действие |
| ---: | --- | --- | --- |
| 0 | true | false | продолжить |
| 1 | true | false | продолжить |
| 2 | false | true | `return 2` |

Трассировка выполняется по реальному коду, а не по общему замыслу. Так можно заметить неверный знак, границу или место `return`.

## Проверяем результат

```js
console.log(missingNumber([3, 0, 1])); // 2
console.log(missingNumber([0, 1]));    // 2
console.log(missingNumber([1]));       // 0
console.log(missingNumber([0]));       // 1
```

Две последние проверки подтверждают обе границы: отсутствуют `0` и `n`.

## Почему функция может не иметь последнего return

По условию ответ гарантирован. Цикл проверяет все допустимые числа от `0` до `n`, поэтому одна из веток обязательно выполнит `return`.

В реальной программе без такой гарантии стоило бы явно вернуть специальное значение или выбросить ошибку. Но менять контракт задачи самостоятельно нельзя.

## Предскажите ошибку

```js
function missingNumberWrong(numbers) {
  for (let candidate = 0; candidate < numbers.length; candidate += 1) {
    if (!numbers.includes(candidate)) {
      return candidate;
    }
  }
}
```

Для какого короткого допустимого входа функция вернёт `undefined`?

<details>
<summary>Ответ</summary>

Например, для `[0]`. Длина равна `1`, но цикл проверит только кандидата `0`. Он присутствует, цикл закончится, а `return` не выполнится. Правильная граница — `candidate <= numbers.length`.

</details>

## Самостоятельная практика

Закройте решение и восстановите функцию по трём строкам псевдокода. Затем добавьте временные `console.log` для `candidate` и результата `includes`. Проверьте вход `[2, 0]`, после чего удалите отладочный вывод.

<details>
<summary>Ожидаемая трассировка</summary>

Кандидат `0` присутствует, кандидат `1` отсутствует. Функция возвращает `1` и не проверяет `2`.

</details>

## Типичные ошибки

- начать код без зафиксированного псевдокода;
- использовать `<` вместо `<=`;
- забыть `!` и вернуть первое присутствующее число;
- поставить `return` после первой проверки независимо от её результата;
- вывести ответ, но не вернуть его;
- сократить работающий код до того, как понятна каждая строка.
